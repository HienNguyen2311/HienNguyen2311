# Learning & Practice Projects 👩‍💻

### [Chest X-ray Images Generation](https://github.com/HienNguyen2311/chest-xray-images-generation)

A comparative study of DCGAN and WGAN-GP models for generating synthetic COVID-19 X-ray images to balance datasets and enhance classification accuracy.

### [Stroke Prediction](https://github.com/HienNguyen2311/stroke-prediction)

A data analysis study using NHANES demographic and questionnaire data to identify key stroke risk factors for rapid patient screening before laboratory testing.

### [Covid-19 Data Visualization](https://github.com/HienNguyen2311/covid19-data-visualization)

An interactive R Shiny application visualizing worldwide COVID-19 data, providing insights into case numbers, vaccination rates, and pandemic spread factors across different countries and continents.

### [Cubicz Price Prediction](https://github.com/HienNguyen2311/cubicz-price-prediction)

An analysis of cubic zirconia stone pricing using linear regression and generalized additive models (GAM) to identify key factors influencing price and build predictive models.

### [Fruits Classification](https://github.com/HienNguyen2311/fruits-classification)

A comparative implementation of deep learning models using CNNs and transfer learning to classify fruit images across cherry, strawberry, and tomato categories.
